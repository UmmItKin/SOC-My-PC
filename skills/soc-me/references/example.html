LOW LLMNR (local-network name lookup)

When DNS cannot find a name, systemd-resolved asks the whole local network and answers others on port 5355. Anyone on the same Wi-Fi can answer first and send you to a fake host. You almost never need it. To undo, delete no-llmnr.conf and restart systemd-resolved.

sudo mkdir -p /etc/systemd/resolved.conf.d
printf '[Resolve]\nLLMNR=no\n' | sudo tee /etc/systemd/resolved.conf.d/no-llmnr.conf
sudo systemctl restart systemd-resolved
